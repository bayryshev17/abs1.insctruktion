BAVABS DRIVER

Инструкция для водителей

Как установить приложение и войти

Прочитайте внимательно. Делайте всё по порядку.

Если что-то не получается — позвоните диспетчеру.

1 Красный экран в Safari

Когда откроете сайт abs1.bavdashboard.ru, может появиться красный экран.

Не пугайтесь. Сайт наш, он безопасный.
  1. Проведите пальцем вниз. Посмотрите вниз экрана.
  2. Нажмите на синюю ссылку «Подробнее...».
  3. Снова проведите пальцем вниз.
  4. Нажмите на синюю ссылку «посетить этот небезопасный сайт».
  5. Сайт откроется.

Каждый раз при новом открытии красный экран может появиться снова. Делайте то же самое.

2 Установка на рабочий стол

После этого приложение будет открываться одним нажатием — как обычная программа.

  1. Откройте Safari. Введите адрес abs1.bavdashboard.ru.
  2. Если появится красный экран — сделайте как в пункте 1.
  3. Внизу справа нажмите «...» (три точки). Потом нажмите «Поделиться».
  4. Появится окно с программами. Проведите пальцем вниз. Или нажмите «Показать больше».
  5. Нажмите «Добавить на экран «Домой»».
  6. Появится окно с иконкой и словом BavABS.
  7. Внизу есть ползунок «Открыть как веб-приложение».
  8. Вверху справа нажмите синюю кнопку «Добавить».
  9. Готово. На рабочем столе появится значок с надписью BAV.
Ползунок «Открыть как веб-приложение» должен быть зелёный. Если белый — нажмите на него.

Дальше открывайте приложение только через этот значок. Не через Safari.

3 Вход в приложение

  1. На рабочем столе нажмите на значок BAV.
  2. Введите свой телефон.
  3. Нажмите «Получить код».
  4. Вам придёт SMS с кодом. Код из 4 цифр. Например: 2419.
  5. Введите код из SMS в поле «КОД ИЗ SMS».
  6. Нажмите «Войти».
  7. Всё. Приложение открылось.

Если ввели не тот телефон:

  • нажмите «Другой номер» и введите телефон ещё раз.

Если SMS не пришла:

  • подождите 1 минуту;
  • проверьте, правильно ли ввели телефон;
  • позвоните диспетчеру.
Доступ — только для водителей BAV
